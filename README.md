# De 29 - Website Cong Thuc Nau An

Website PHP + MySQL + phpMyAdmin + Nginx,
trien khai bang Docker Compose.

## Khoi chay
1. Tao file .env tu .env.example.
2. Thay mat khau mau bang mat khau manh.
3. Chay: sudo docker compose up -d --build

## Truy cap
- Website: http://localhost
- Website tu may Windows: http://IP_MAY_AO
- phpMyAdmin: localhost:8081 qua SSH tunnel

## Kiem tra
sudo docker compose ps
sudo docker compose logs --tail=50
